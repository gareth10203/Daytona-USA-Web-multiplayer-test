# Daytona USA Web — revisión 35 UIX experimental

Single Player abre su propio modal para elegir Normal, Grand Prix o Endurance, dificultad, dirección normal o inversa y coches CPU. Las preferencias se guardan en el dispositivo. Sin coches CPU se utiliza el Time Attack original de una cabina independiente.

La cabina continúa en SINGLE, DELUXE y región Export. No crea una sala ni habilita el enlace. Los tres circuitos se seleccionan dentro del arcade. Reanudar con los mismos ajustes conserva la partida; aplicar cambios reinicia la cabina y conserva los datos de puntuaciones.

Ejecutar `node scripts/serve.js dist 8117` y abrir http://localhost:8117. Para GitHub Pages, subir el contenido del ZIP. No contiene ROM. En multiplayer, todos los jugadores deben utilizar la misma revisión. La revisión 34 y su ZIP permanecen separados; se conservan sus correcciones de checkpoints y protección gráfica.
