Daytona USA — WebGPU + WebAssembly

Serve this folder with:
  node serve.js . 8080
or:
  python -m http.server 8080

Open http://localhost:8080 and import your Revision A (1994) ROM ZIP.
A WebGPU browser is required. Do not open index.html through file://.

First run: SINGLE link, DELUXE cabinet type, Export region, zero credits.
Let attract mode play, or insert a coin to race. Existing saves receive a
one-time DELUXE update while preserving scores and unrelated settings.

Arrow keys: steering and pedals. 5: coin. Enter: start.
1–4: gear. Q/W: shift down/up. A/S/D/F: camera views.
Gamepad: left stick, RT/LT pedals, B/A/X/Y gears 1/2/3/4, Back coin,
LB/RB shift down/up (one gear per press).
Start start, D-pad up/right/down/left camera views 1/2/3/4.
Stick steering has an 8% dead zone and a gentler progressive response.
Controller vibration follows the game's arcade drive-board commands.
Set its intensity in the controls menu (0 = Off); default 100%.
Separate Centring feedback defaults to 5% and uses the arcade spring force
and actual steering position. It is silent in the spring's dead zone.
Feedback grows gradually across the steering travel, following the game's
commanded spring strength; small turns produce only a gentle cue.
Set Centring to Off to keep only the other vibration effects.
Requires a browser/controller supporting dual rumble. Pausing stops it.
Accelerator confirms course and car selections.

F2 opens original arcade settings. F/S moves the cursor; D/S changes values;
Enter selects. Choose EXIT to return. F3 is the service button.
Escape opens/closes the import menu and pauses/resumes the game.
Enhanced is the default: native window resolution and a wider 3D camera view.
Enhanced defaults to scenery draw distance +2 on desktop, +1 on mobile.
Classic restores the original arcade resolution, aspect ratio and draw distance.
Phone: left pad steers; GAS/BRAKE are pedals; +/− shifts; VIEW changes camera.
COIN adds credit; START starts. Menu pauses; ⋯ reveals F2/settings controls.
Use landscape for widescreen. Portrait keeps the full original HUD visible.
Move the pointer for menu, sound and fullscreen buttons.
Settings are saved locally for this browser and server address.

Verified with the original engine and supplied ROM in Chrome/NVIDIA:
boot, attract mode, track selection, racing and local saves.
Audio fidelity has not been certified. See LICENSE and THIRD_PARTY.md.
This package does not include the ROM ZIP.

Settings opens Graphics, Control, Keyboard (Touch controls on mobile), Sound
and Experimental categories; Back/Esc returns.
Graphics: Classic (original distance), 1x (mobile default), or 2x (desktop default; more scenery).
Sound: game volume slider. Changes save automatically on this device.
The main vibration checkbox retains intensity settings when switched off.

Joystick sensitivity is adjustable from 25% to 175%. The 100% default keeps the existing softened response, 8% dead zone and full steering range. Personal sensitivity and graphics selections are saved; device defaults apply when no graphics selection is saved.
Experimental wheel setup: Settings > Experimental. Select the device,
assign steering and capture centre/full-left/full-right before enabling.
Assign and calibrate pedals (released/fully pressed); separate USB pedals,
inverted inputs and combined axes are supported. Map gears, paddles, views,
coin and Start in Gears & buttons. Live inputs help verify the profile.
Wheel devices must be exposed by the browser/OS. Press a device button to
reveal it; PC mode and manufacturer drivers may be needed. No model-specific
wheel force feedback is sent. Profiles save locally per reported device ID.


SEPARATE MULTIPLAYER EXPERIMENT
After ROM validation choose Single Player or Multiplayer. Create a private
room, share its invitation and accept your friends. Everybody marks Ready;
the host starts with shared mode/difficulty and Export region. Host MASTER,
guests SLAVE. The arcade still uses coins and original course/car selection.
ESC and settings do not pause linked play. Leaving ends the linked session.
PeerJS Cloud handles signaling; WebRTC carries original arcade link bytes.
Some networks need a TURN service, not included by default. Keep tabs visible.
No hot joining during linked play. Up to 8 players; WAN behavior experimental.
